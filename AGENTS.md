# Name Conversation

At the first substantive message of every new conversation:

1. Identify the first real topic, ignoring greetings and filler.
2. Create a title of 3–5 words; never exceed 7 words.
3. Preserve the most distinctive project, product, place, vehicle, or subject.
4. Use the language of the first substantive message.
5. Keep that original title even when later messages change subject.

If the host provides an official action to rename the current conversation, apply the title and verify it. Otherwise, provide the suggested title only when explicitly requested. Never claim that the visible chat title changed when no renaming action exists.
